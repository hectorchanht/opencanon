OpenCanon

What we built for ourselves must become infrastructure for everyone — a personal canon brain anyone can run. AI infrastructure for the People: everyone will need it, just like we do.

Founding — initialized, first release in preparation

What it is

Build a Canon-grade Notion-like system: a personal canon brain anyone can run — an online canonical database with CLI + MCP + JS API surfaces, provider-agnostic (no single platform holds the kill switch), offline-first, all languages day one.

Core jobs: capture raw → distill → enrich (visible) → merge/dedupe → gate → surfaces (notes/API/MCP) → teach-back.

Its root: the Notion brain — the Canon of the Canon of the Canon, the original database where canon first lived. Apple Notes is the body-close distilled surface of that root, not the root itself; learnings flow back up the same pipe and re-distill into the root.

Family position: OpenVehicle makes facts citable, OpenOracle fills the public face, DawnGlance gives form — OpenCanon is the BRAIN they all read from: the canonical store itself.

Dogfood № 1: Hector's own Notion brain + the Dawn canon. For the People: free base forever (Dawn money model); credits meter volume/API.

Name note: OpenCanon is the working name; formal naming runs through the Name Canon process.

End Goal

AI infrastructure for the People: a Canon-grade personal canon brain anyone can run — the canonical store every surface reads from, with no single platform holding the kill switch, and a free base forever.
